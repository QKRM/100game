# 100 만들기

초·중등 학습자용 2인 로컬 대전 수학 게임 (PWA). 빌드 도구·프레임워크·외부 라이브러리 없이
순수 HTML / CSS / JavaScript 로만 동작하며, 오프라인에서도 실행됩니다.

플레이: https://qkrm.github.io/100game/

## 규칙

점수 0에서 시작합니다. 카드를 뽑으면 그 숫자 `n` 을 **일의 자리(+n)** 또는
**십의 자리(+n×10)** 중 하나에 더합니다. 100에 가장 가까운 점수를 만들면 이기고,
**100을 넘는 순간 그 자리에서 집니다.** (100에 딱 맞추는 것은 괜찮습니다.)

### 탐구 모드
- 덱: 1~6 각 1장, 총 6장. 두 사람이 카드를 공유합니다.
- 카드 한 장이 공개되면 두 사람이 각자 독립적으로 자리를 고르고, 둘 다 고른 뒤 함께 공개됩니다.
- 6장을 모두 쓰면 종료. 100을 넘지 않은 사람 중 100에 가까운 쪽이 승리합니다.

> 이 모드의 최종 점수는 항상 `9A + 21` (A = 십의 자리로 보낸 카드들의 합) 입니다.
> 따라서 가능한 점수는 21, 30, 39, 48, 57, 66, 75, 84, 93, 102 … 뿐이고
> **100은 정확히 만들 수 없으며 넘지 않는 최고점은 93** 입니다.
> 이는 버그가 아니라 의도된 설계이며, 학습자가 이 규칙성을 스스로 발견하는 것이 목적입니다.

### 확률 모드
- 덱: 1~6 각 4장, 총 24장을 두 사람이 공유합니다.
- 첫 번째 사람이 자기 차례를 모두 끝낸 뒤 두 번째 사람이 진행합니다.
- 매번 **카드 뽑기** 또는 **멈추기**를 고릅니다. 최소 1장은 반드시 뽑아야 합니다.
- 남은 카드 개수를 보여주는 토글이 있습니다(기본 켜짐).
- 덱이 공유되므로 이 모드에서는 100을 정확히 만들 수 있습니다. (예: 40 + 50 + 4 + 6 = 100)

## 파일

```
index.html      화면 3개(시작·게임·결과) 마크업
style.css       스타일 (큰 숫자, 최소 48px 터치 영역)
app.js          게임 로직 전체
manifest.json   PWA 매니페스트
sw.js           서비스 워커 (앱 셸 캐시, cache-first)
icons/          앱 아이콘 192 / 512
```

## 실행

정적 파일만으로 동작합니다. 아무 정적 호스팅에 올리거나, 로컬에서는 간단한 정적 서버로 열면 됩니다.
(서비스 워커 등록은 `http(s)` 환경에서만 동작하므로 `file://` 로 열면 오프라인 캐시만 빠집니다.)
